# Prism visual identity — "Refraction"

Goal: a reply that reads like a beautifully typeset editorial page that comes alive. Not a UI kit. Every component should feel bespoke: a designer would recognise Prism in one screenshot.

## Signature ideas (use everywhere, sparingly)
1. **Spectrum.** Prism's one signature: a thin spectral gradient (light through a prism)
   `--prism-spectrum: linear-gradient(90deg,#7DD3FC 0%,#818CF8 30%,#C084FC 55%,#F472B6 80%,#FDBA74 100%)`.
   Used ONLY for: the streaming reveal sweep, focus rings, the current/active indicator (progress rails, winner edge, live-number underline on hover), the composer focus glow. Never as big fills. In dark mode it glows (blur shadow at 35% opacity).
2. **Editorial type.** Pair a refined grotesk for UI/body with a high-contrast serif for "moments": headlines of insights, big totals, verdicts, questions.
   - Body/UI: "Inter" var (font-feature-settings "cv11","ss01","ss03"), 15.5px/1.65 body, -0.006em.
   - Display/moments: "Instrument Serif" (Google Fonts; fallback "Iowan Old Style", Georgia), used at 28–44px, -0.01em, for: chart headline, estimate total, pick verdict, troubleshooter question, summary title.
   - Mono: "JetBrains Mono" 13px for code, commands, keyboard hints.
   - Numerals: tabular-nums everywhere figures align; serif oldstyle-free lining figures for big totals.
3. **Paper & ink.** Light: paper `#FBFAF7`, ink `#1A1916`, ink-2 `#5E5B54`, ink-3 `#9A968D`, hairline `rgba(26,25,22,.09)`, fill `rgba(26,25,22,.035)`, fill-strong `rgba(26,25,22,.06)`. Dark: paper `#0F0F11`, ink `#EDEBE6`, ink-2 `#A6A39C`, ink-3 `#6E6B65`, hairline `rgba(237,235,230,.09)`, fill `rgba(237,235,230,.04)`.
   Accent: ink-violet `#5747FF` (dark: `#8B80FF`), accent-soft 8% tint. Positive `#0F9D6B`, caution `#C2780A`, negative `#D4463B` — muted, only as small marks.
4. **No boxes.** Components live on the paper. Separation = whitespace, hairlines, soft fills, typographic scale. Only three things may have a surface: code, canvas (mockups/artifacts), and floating overlays (popover, menu, toast) which use `--prism-shadow-float: 0 1px 0 rgba(0,0,0,.04), 0 12px 32px -8px rgba(20,18,40,.18)` and 14px radius.
5. **Motion = materialising light.** Easing `cubic-bezier(.2,.8,.2,1)` (out-expo-ish) 420ms for entries, spring `cubic-bezier(.34,1.56,.64,1)` 300ms for toggles. Streaming: each block fades from 0→1 opacity with 6px rise and a 1-shot spectral shimmer sweeping left→right across it (a masked gradient pass, 700ms). Numbers roll digit-by-digit (odometer). Reorders use FLIP. Checks draw (stroke-dashoffset). Charts draw their line then fade the area. All off under reduced motion.
6. **Micro-language (shared primitives, identical everywhere).**
   - Pill button (primary): ink background (#1A1916, dark: #EDEBE6) with paper text, 36px tall, 999px radius, 15px 550 weight, subtle inner highlight; on hover lifts 1px; when sent morphs into a check + past-tense label with a spectral flash. Secondary: fill background. Ghost: text only.
   - Chip/toggle: 30px, fill bg, ink-2 text; on = ink text + accent-soft bg + 1px accent inner ring.
   - Stepper: "− 5 +" inline, number in tabular serif? No: tabular Inter 600; buttons are 24px round ghost.
   - Switch: 30x18 track, spring knob.
   - Check: 18px rounded-6 square, hairline; checked = ink fill with drawn paper check.
   - Icon buttons (undo, ask): 28px ghost, ink-3, appear on hover/focus-within of the component (always on touch).
   - Inline editable value: dotted underline in ink-3, hover → spectral underline, drag horizontally to scrub (cursor ew-resize), click to type.
   - Kbd hint: tiny mono in fill.
7. **Rhythm.** Max measure 680px for prose; components align to the same left edge; wide components (chart, table, canvas) may extend to 760px centred. Flow gap between blocks = 20px; component internal spacing on an 4px grid. Titles of components are 15px 600 ink (like a run-in heading), never a bar.

## Component concepts (each must be bespoke)
- **Pick for me ("Verdict")**: top: "What matters to you" with 3–4 weight controls as mini segmented dots (0–3) per criterion. Options are laid out as columns separated by hairlines (no tile boxes). Each column: name (17px 600), one-line tagline, a criterion matrix as small horizontal bars, pros/cons as ✓/– lines. Score shown as a big serif percent with a thin circular arc. Columns re-order with FLIP as weights change; the winner column gets a 2px spectral top edge and a serif verdict sentence above all columns: "*Concierge pilot* wins — it's strongest on learning, which you weighted highest." Primary: "Go with Concierge" pill under the verdict (label updates with winner).
- **Estimate ("Receipt")**: lines are item name + meta on left, inline stepper/switch + amount right; turning an item off strikes through and fades it. Above total: a single 6px rounded composition bar split by item (each segment a tint of accent, hover shows item). Total in 44px serif with odometer roll. "Use this estimate" pill. Sent state: pill → "✓ Sent · 6 seats · $324" and a calm spectral line sweeps under the total once.
- **Live numbers**: inline tokens in prose; dotted underline; drag to scrub with a tiny floating readout above cursor showing min–max track; dependent numbers in the paragraph roll and get a brief accent-soft highlight behind them.
- **Answer chart**: serif headline insight (32px) with a supporting line; chart frameless with hairline grid only on y ticks, gradient area (accent 18%→0), line 2px; annotation as a small label pinned with a dotted leader line; hover crosshair with a floating value card; pivots as a quiet segmented control (text tabs with sliding underline) top-right. Line draws on mount.
- **Runbook**: left rail 1px hairline; progress fills the rail with the spectrum as steps complete. Step markers: 22px circles (number → drawn check). Done steps collapse to a single struck-free muted line with time stamp "done". Current step: title 16px 600, body, command row rendered as a mono line on fill with a `$` prompt and copy icon at end (copied → check). "Stuck here?" is a ghost text link that appears on the current step. Header: title + "2 of 5" + tiny percent.
- **Troubleshooter**: a mini path map at top: small dots connected by lines showing steps taken (filled), the current (spectral ring) and remaining branches faintly — like a subway line. Question in 28px serif. Yes / No as two large pills (Yes = ink, No = fill) with kbd hints Y/N. Past answers listed as compact lines with a ✓/✕ glyph, clickable to rewind. Resolved: big serif "Fixed." with green check drawn; dead end: "Let's hand this to a human" with "Send what we tried" pill.
- **Summary with sources**: bullets as prose; citations are superscript numbered chips; on wide screens the source quote appears as a sidenote in the right margin aligned to the bullet (Tufte-style), on narrow screens it expands inline under the bullet as an indented italic quote with source name. Action items: checklist with drawn checks, avatar initials circle, due date in ink-3; "Send 2 action items" pill.
- **Inline ask**: a sentence in 20px serif-ish prose where missing fields are inline inputs with dotted underline, pre-filled guesses in ink-3 italic until confirmed: "Plan a kickoff for *Fieldnotes* with *5* people on *Fri 28 Nov*." Additional long field as a borderless textarea with hairline bottom. Pill "Plan the kickoff".
- **Table / DataTable**: no outer border; header 12px uppercase-free 600 ink-3 with sort arrows on hover; rows 44px with hairline separators; numeric columns right-aligned tabular with an optional faint inline bar behind the value showing magnitude; row hover = fill; selection = check + accent-soft row; footer: pagination as "1–4 of 6  ‹ ›" ghost; filter as an inline search field with hairline bottom.
- **Code block**: the one surface: fill-strong bg, 12px radius, filename/lang as tiny mono label top-left inside, copy appears on hover top-right, line numbers ink-3, highlighted lines with accent-soft band. Theme: refined, low-saturation (strings warm, keywords violet, numbers teal).
- **Callout**: no box. 2px left bar (spectrum for "tip", accent for note, caution colour for warning) + small icon + 600 title run-in + body.
- **Tabs**: text tabs with a sliding 2px underline (spectrum when focused), content cross-fades.
- **Card / grid**: "cards" are columns separated by hairline vertical rules, title 16px 600, body, optional pill. Grid = responsive columns.
- **Badge**: tiny 22px pill fill with dot.
- **Mockup**: canvas sits on a subtle dotted artboard field (radial dots on fill) bleeding to 760px; device frame floats with float shadow; device switcher + zoom as a floating glass pill (backdrop-blur) top-centre on hover. Comment mode: cursor becomes a comment bubble; pins are 26px avatar-bubbles with numbers, popover is a float card with textarea and "Comment"; region is a dashed accent rect. Submit bar: floating pill bottom-centre "3 comments · Submit feedback".
- **Artifact**: same canvas language; title + version as small run-in above; floating glass toolbar (code, copy, download, fullscreen, versions) on hover; loading = spectral shimmer skeleton; errors = calm inline note + "Fix this" pill.
- **Chat shell**: paper background, no sidebar border (sidebar on slightly darker paper), centred 720px thread, user messages right-aligned ink-on-fill bubbles 18px radius, assistant has no bubble and a small Prism glyph; composer = floating 56px pill-ish (22px radius) with float shadow, spectral focus ring, send button ink circle; "thinking" = three-dot spectral shimmer; streaming caret = 2px spectral bar.
